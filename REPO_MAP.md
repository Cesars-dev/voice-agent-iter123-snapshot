## 10 · The laws in one glance  (full text in AGENTS.md / DOCTRINE.md)

- **LAW 0 — the git crystal ball.** CODE = branch `engine/iterNN-<slug>` → suite green →
  battery → report → **ASK JULIO** (no code merges without it). DOCS/md = straight to main.
  History surgery (rebase / force / delete) always needs say-so.
- **Iteration numbering.** "iter" only increments for branches touching `engine/diallux/`.
  Everything else rides the current number with a suffix (`iter95/sdk`).
- **MODEL LAW.** Agent LLM = `gpt-5.4` everywhere. Runtime switch = `OPENAI_MODEL` in
  `engine/.env`; `llm.json`'s model field is display-only dead metadata.
- **VOICE LAW.** ElevenLabs is DEFAULT (prod = Hannah, tests = Sarah). Cartesia only for
  HIPAA / low-quality lanes. Never drop the dated `CARTESIA_MODEL_ID` pin on env edits.
- **Evidence.** Transcripts, reports, dumps → `research/` (gitignored). Never inside
  `engine/` or `retell/`. `_cold_archive/` is write-only history.
- **KB policy.** Reuse / upsert via `retell/sdr/config/kb_registry.json` — never
  hand-create KBs. Never touch live agent IDs without a plan + owner instruction.
